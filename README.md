# Customer Churn Prediction Dashboard

An interactive Machine Learning dashboard that predicts whether a telecom customer is likely to leave the company.

## 🚀 Live Demo
https://customer-churn-prediction-l7u7fecdwikp3buworhcpq.streamlit.app/

## 📌 Project Overview
This project uses customer information to predict churn and help telecom companies identify customers who may leave their services.

## 🛠️ Technologies Used
- Python
- Pandas and Scikit-learn
- Matplotlib and Seaborn
- Streamlit
- Joblib

## 🤖 Machine Learning Models
- Logistic Regression
- Random Forest Classifier

## ✨ Features
- Interactive customer details input
- Customer churn prediction
- Machine learning model comparison
- Web-based dashboard

## 💻 Run Locally
1. Clone this repository.
2. Install the required libraries:
   "pip install -r requirements.txt"
3. Run the dashboard:
   "streamlit run app.py"
